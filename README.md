#### 🛠 What I bring to the table:

* **Modern Frontend Architecture:** Building scalable Single Page Applications with **React 19**, **TypeScript**, and state management; writing maintainable CSS architectures using **Tailwind CSS v4**, **SCSS**, and **BEM**.
* **Interactive UI & 3D / Web Audio:** Crafting smooth hardware-accelerated animations and interactive interfaces using **GSAP**, **Canvas 2D**, and **Web Audio API**.
* **Performance & Quality:** Optimizing Core Web Vitals (speeding up page load by 30–40%, achieving 95+ scores in Lighthouse), asset optimization (WebP, code-splitting), and automated unit testing with **Vitest**.
* **Build Tools & Workflow:** Modern development setups using **Vite**, **TypeScript**, Docker, and CI/CD automation with GitLab CI & GitHub Actions.

#### 🔧 WordPress API & Architecture:

REST API, Rewrite API, WP_Query, `$wpdb`, HTTP API, WordPress Hooks (actions & filters). OOP (classes, methods), separation of concerns (logic / data / templates), custom Gutenberg blocks, Composer autoloading (PSR-4).

#### ☁️ Cloud & Hosting:

Hosting setup, SSL configuration, domain/DNS management, deployment (shared hosting, VPS, GitHub Pages).
